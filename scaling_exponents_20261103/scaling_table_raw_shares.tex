\raggedright\footnotesize
\textbf{Notes.} Blue rows are LDA and orange rows are HSE06. $P_3$ is the full FHI-aims polarization (ionic plus branch-mapped Berry and dipole terms) along reciprocal-lattice vector 3, reported from the 128-core dipole calculation. All ratios use $|P_0|$, the magnitude of the polarization quantum: 64.767 mC/m$^2$ for the 4$\times$4$\times$4 supercell and 16.192 mC/m$^2$ for 8$\times$8$\times$8. Thus $P_3/|P_0|=P_{\mathrm{ion}}/|P_0|+P_{\mathrm{Berry}}/|P_0|+P_{\mathrm{dipole}}/|P_0|$, subject to rounding. Max. tracked memory is the largest FHI-aims code-tracked value over each series' archived SCF and dipole runs, reported as the maximum per-rank value multiplied by 128 (all maxima occur in the 128-core dipole run); the parenthetical percentage uses the Slurm memory capacity of the partition for that run. This is not Slurm MaxRSS. The percentage columns use the raw FHI-aims component timers divided by the sum of those four timers and report the range over measured core counts.
