Build dataset to compute Born Effective Charges as derivative of polarization/dipole w.r.t. nuclear displacements.
The script reads either polarization or dipole from DFT output files.

Input parsing is controlled via '--format'. This can be:
  (1) a predefined format key
  (2) a JSON file defining a custom format

Each format defines:
  - type: polarization or dipole
  - regex: extraction pattern
  - factor: unit conversion factor
  - drop_patterns: optional lines to ignore

Available formats:
aims_polarization, aims_dipole
