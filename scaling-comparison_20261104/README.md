# BaTiO3 scaling comparison

`plot_comparison.py` makes the new Figure 7 PDF at
`../figures/Figure-7.pdf`.

- The right panel reuses the timing data and fits from the left panel of
  Figure 7.  Those reference calculations use LDA, so their series use the
  LDA colour in the shared legend.
- The left panel is a comparable log--log timing plot from
  `../scaling_exponents_20261103/timing_data.csv`.

The left panel compares LDA and HSE06 for both the 4x4x4 and 8x8x8 cells.  It
uses the smallest available polarization grid for each supercell: `3 4 2 2`
for 4x4x4 and `3 2 1 1` for 8x8x8.  Its series identifiers and plotting
styles are deliberately grouped near the top of `plot_comparison.py` so they
can be customized without changing the plotting machinery.

Two separate legends sit beside the right panel.  Colour identifies the
functional and marker shape identifies the supercell; polarization grids are
documented here rather than shown in a legend.

Both panels have broken logarithmic y axes.  The left panel uses equal-height
segments and omits the interval from 100 to 375 seconds.  The right lower
axis is 50% taller and its logarithmic span is enlarged by the same factor,
so equal power laws remain visually parallel; it omits the interval from about
3,486 to 4,000 seconds.  Both discontinuities are marked by diagonal slashes
on the axes.

## Customize the plot

The `User-editable configuration` block at the top of
`plot_comparison.py` contains the controls intended for routine changes:

- `LEFT_PANEL_SERIES` selects the left-panel data; `LEFT_PANEL_STYLES` sets
  each selected series' colour, marker, and exponent-label position.
- `*_YLIM`, `UPPER_Y_SPAN_FACTOR`, and
  `RIGHT_LOWER_TO_UPPER_HEIGHT_RATIO` control each broken y axis.  Keep the
  right lower span derived from its height ratio if you want equal power laws
  to remain visually parallel across its two segments.
- The `*_ANNOTATION` values position the `m=...` and ideal-scaling labels in
  axes fractions.  `OUTER_PANEL_WSPACE`, `SUBPLOT_BOUNDS`,
  `Y_LABEL_POSITION`, and the legend coordinates control the overall layout.
- Colours, fit/guide-line styles, ticks, figure size, and output path can all
  be changed there without editing the plotting functions below.

## Run

From this directory:

```bash
python3 plot_comparison.py
```

The script uses the shared plotting style and Figure 7 data from its parent
FHI-aims workspace.  It also reads the scaling-exponent CSV in place, so do
not move this directory away from that workspace without updating the path
constants at the top of the script.

The companion component breakdown is generated with:

```bash
python3 plot_component_scaling.py
```

It writes three variants in this directory: `Figure-7-components.pdf` contains
both horizontal grids and pale-navy ideal-scalability lines,
`Figure-7-components-grid.pdf` contains only the grids, and
`Figure-7-components-ideal.pdf` contains only the ideal-scalability lines.
All three use the four selected left-panel series plus the two dense-LDA
right-panel series. The dense component timings are re-extracted from the
bundled FHI-aims outputs by `extract_dense_components.py`.
The source outputs are kept under `dense_raw/` and the extracted table is
`dense_component_data.csv`.

The corresponding positive log--log scaling exponents `m` (with one-standard-
error bars) and the resolved cost shares are generated by
`plot_component_exponents_split.py` (also used when running
`plot_component_exponents.py`).  They write
`../figures/Figure-7-component-exponents.pdf` and
`../figures/Figure-7-component-shares.pdf`, respectively.  The exponent plot
includes the two dense-LDA fits from the right panel of Figure 7.  The share
plot shows the four non-total components at each available core count; every
stacked bar sums to 100%.

The Python environment needs `numpy`, `pandas`, and `matplotlib`; the latter
uses the workspace's LaTeX-enabled Matplotlib style.
