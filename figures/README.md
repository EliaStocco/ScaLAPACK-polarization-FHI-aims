# Figure outputs

These entries are relative symbolic links to the generated data figures used
by the ScaLAPACK manuscript. Each plotting script writes its canonical PDF
beside its own data and source code; the files in this directory are only the
manuscript-facing links. Regenerating a canonical PDF therefore updates the
manuscript asset immediately. Use `readlink figures/<file>.pdf` to inspect a
link target.

## Repository-maintained diagrams

Figures 1, 2, and 4, together with the unnumbered Berry-phase link schematic,
are conceptual TikZ graphics rather than data plots.  Their sources are
`figures/Figure-1-source.tex`, `figures/Figure-2-source.tex`,
`figures/Figure-4-source.tex`, and
`figures/berry-phase-links-source.tex` in the manuscript repository.  Run
`./figures/build-figures.sh` there to regenerate the corresponding PDFs.

## Main-text figures

### Figure 3 — spline interpolation

Generated by `spline/plot.py` from `spline/dataframe.csv`.  The CSV contains
polarization components extracted from the spline and non-spline calculations.
The script projects the three components onto `[111]`, uses the finest spline
grid as the reference, and plots the absolute deviation versus `k_grid`.
Rows with `k_grid < 2` or missing polarization components are discarded.

### Figure 5 — LAPACK/ScaLAPACK comparison

Generated by `comparison/2x2x16/plot.py` from
`comparison/2x2x16/dataframe.csv`.  The CSV stores timing and peak-memory
values extracted from the completed FHI-aims runs.  Net polarization time is
the `dipole` time minus the corresponding `scf` time; peak memory is the
maximum tracked value per core.  The plot retains runs with at most 1024
cores.

### Figure 6 — atom-count scaling

Generated by `scaling-atoms/plot-left_top.py` from
`scaling-atoms/dataframe.csv`.  Run `scaling-atoms/extract.py` first: it parses
completed `aims.out` files for atom counts, node/core counts, total timing,
polarization timing, BLACS grids, and ScaLAPACK task information.  The plot
keeps only atom counts 4, 16, 64, 256, and 1024.  Fits are performed in
log--log space on those selected points.

### Figure 7 — BaTiO3 and water core scaling

Generated by `corrected-polarization-scaling-20261106/plot_figure7.py`. The
left panel reads the corrected polarization-scaling data, while the right
panel retains the original reference data. The output is written to
`corrected-polarization-scaling-20261106/Figure-7.pdf`.

The component breakdowns are generated by
`corrected-polarization-scaling-20261106/plot_component_scaling.py`. The
outputs `Figure-7-components.pdf`, `Figure-7-components-grid.pdf`, and
`Figure-7-components-ideal.pdf` contain six panels: the first four use the
corrected data and the last two retain the original dense/reference data.

The exponent and resolved-share plots are generated by
`corrected-polarization-scaling-20261106/plot_component_exponents.py`, which
uses the local adapted data and the original Figure 7 plotting style.
`Figure-7-component-exponents.pdf` shows the log--log scaling coefficients
with one-standard-error bars, while `Figure-7-component-shares.pdf` shows
the four non-total component shares at each measured core count as stacked
tiles normalized to 100%. These PDFs are written in the corrected-data
directory.

## Supplementary figures

### Figure S1 — atom-scaling timing components

Generated by `scaling-atoms/plot_right.py` from the same
`scaling-atoms/dataframe.csv` produced by `extract.py`.  It plots the
ScaLAPACK total polarization time and its extracted Fourier, dipole-matrix,
dipole-term, Berry-term, and density-convergence components.  It uses the
same five selected atom counts as Figure 6.

The combined plot `Figure-S1-components.pdf` is generated by
`scaling-atoms/plot_component_exponents.py` and written to `scaling-atoms/`.
It contains the exponent and share panels with one shared legend.  The panels use the seven ScaLAPACK
points at 16, 32, 64, 128, 256, 512, and 1024 atoms.  The first plot shows
signed log--log component exponents for ``time \propto x^m`` with
one-standard-error bars; the second shows
the four non-total component costs as atom-resolved stacked shares normalized
to 100% at each atom count.

The former separate Figure S1 exponent and share PDFs are obsolete; use the
combined `Figure-S1-components.pdf` plot.

### Figure S2 — water scaling

Generated by `performance-water/final-alltoall-load/plot.py` from
`performance-water/final-alltoall-load/analysis-dataframe.csv` and
`fit.json`.  The analysis dataframe is assembled from the completed water
calculations for the three functionals and the 128, 196, and 256 molecule
boxes; `fit.json` contains the corresponding log--log fit parameters.  The
script plots net polarization time versus core count together with fitted and
ideal-inverse scaling lines.  The fit convention is
``polarization_time_s = A * ncores**(-m)`` with positive ``m``.

The companion exponent bar plot is generated by
`performance-water/final-alltoall-load/plot-table-S6.py` and written as
`table-S6-scaling-exponents.pdf` in that directory.  It visualizes the same
positive exponents with their one-standard-error uncertainties from Table S6.

## Regenerating

Run the producer script from the workspace root (or from its own directory as
documented in the workspace README).  Each producer writes its PDF to its own
data/source directory.  The PDFs in `figures/` are symbolic links to these
outputs, so no manual copy step is needed.

For the current Figure 7 set, for example:

```bash
python corrected-polarization-scaling-20261106/plot_figure7.py
python corrected-polarization-scaling-20261106/plot_component_scaling.py
python corrected-polarization-scaling-20261106/plot_component_exponents.py
```
